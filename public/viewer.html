Use Phebcam in OBS

  1. Open OBS
  2. Add a Browser Source to your scene
  3. Enter this Phebcam viewer URL (OBS-optimized) in the source
  4. Set the Browser Source width/height to match your phone's video
  5. Select the Phebcam source in your scene
  6. Click "Start Virtual Camera" in OBS
—

Once "Start Virtual Camera" is running, apps like Zoom, Discord, Google Meet, and Teams can select OBS Virtual Camera as their camera source. Phebcam does not create a system camera device itself — OBS handles that step.

Phebcam Viewer → OBS Browser Source → OBS Scene → Virtual Camera → Zoom / Discord / Meet

Networking: Same network / local testing is supported where your browser's security requirements are met. Connecting across different networks may fail — Phebcam does not currently use a TURN relay server, only direct peer-to-peer connectivity.

Privacy: Camera access on the phone requires browser permission. Video is transmitted using WebRTC directly between the phone and this browser. The signaling server only relays connection setup messages and does not store camera recordings. No recording happens unless you explicitly record through another application such as OBS.
